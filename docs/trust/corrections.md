# Corrections and disputes

## Corrections

Every correction to a published figure is dated and left visible. A corrections page lists them newest first, with what was shown, what it was changed to, and why. A figure is never silently replaced.

## Disputes from a provider or insurer

A provider or insurer that believes a figure is wrong writes to the address on the site. The process:

1. We re-run the pipeline against the source file we recorded (URL, hash, date) and against the current file.
2. If our figure matches the file, the figure stands and the exchange is published as a **Statement** beside it, quoted and dated.
3. If our figure does not match the file, we correct it, date the correction, and publish the exchange.
4. If the file itself changed, the diff report shows it, and both versions are kept with their dates.

The record is the file. We do not adjudicate whether the file is right; we show what it says and what the provider says about it.

## Disputes about a submitted record

A submitter withdraws by code. A provider named in a submitted record may state that the record is wrong; the statement is published beside the record, labelled, and the record stays unless the submitter withdraws it or our own re-check of the extraction finds an error.
